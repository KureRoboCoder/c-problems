# Q1B	 	ice cream

## 問題文

「アイス」と分類されるものにはアイスクリーム、アイスミルク、ラクトアイス、氷菓の4種類程度あります。
これらは乳固形分と乳脂肪の割合で決まります。

その割合は次の表のように決まっています。

| 分類名 | 乳固形分の割合 | 乳脂肪の割合 |
| ---- | ---- | ---- |
| アイスクリーム | 15.0% 以上 | 8.0 % 以上 |
| アイスミルク | 10.0% 以上 | 3.0 % 以上 |
| ラクトアイス | 3.0% 以上 | 条件なし |
| 氷菓 | 条件なし | 条件なし |

条件の優先順位は
アイスクリーム　> アイスミルク > ラクトアイス > 氷菓
という順番です。

乳固形分の割合
$N$と、乳脂肪の割合
$M$が与えられるため、どの表記名となるかを出力してください。

ただし、出力する際は
「アイスクリーム」は`cream`
「アイスミルク」は`milk`
「ラクトアイス」は`lact`
「氷菓」は`ice`
としてください。

## 入出力例


**入力**

$N \ M$

**出力**

$S_o$

乳固形分の割合
$N$と、乳脂肪の割合
$M$で与えられる

$S_o$ は答えとなる文字列

## 制約

小数
$N$は小数点第一位までの精度とする

小数
$M$は小数点第一位までの精度とする

$0.0 \leq N < 100.0$
$0.0 \leq M < 100.0$
$0.0 \leq N + M < 100.0$

## サンプルケース

### 例1

入力

### `10.0 8.2`

出力

### `milk`

乳固形分の割合が条件を満たしていないため、アイスクリームではありません。
乳固形分の割合と乳脂肪分の割合の条件を初めて満たすのはミルクアイスのため、`milk`と出力してください。


### 例2

入力

### `31.1 0.0`

出力

### `lact`

乳脂肪の割合が条件を満たしていないため、アイスクリームでもミルクアイスでもありません。
乳固形分の割合と乳脂肪分の割合の条件を初めて満たすのはラクトアイスのため、`lact`と出力してください。
