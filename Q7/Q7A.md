# Q7A 	研究対象 XY

## 問題文

よくあるラノベのようにハーレムを作りたいと願っているDr. XYさん

人間の生まれる比率や自分好みの姿にさせる薬などを開発してきたかったらしいですが、今のところ何一つとしてうまくいっていません

人間、自分が望むこと何でもできるわけではないのです

ただ、少しだけお手伝いをしてあげましょう！

Dr.XYさんが作ったものは特殊染色体
$X$ というもので、これは1分で次のようなことが発生します

- 両隣を特殊染色体
  $X$にする

これを**変化がなくなるまで限りなく長い時間**放置した時の、染色体
$X$ の数はどうなるでしょうか？

文字列
$S$ が与えられます

変化がなくなるまで操作を加えたときの染色体
$X$ の数を出力してください

## 入出力例

**入力**

$S$

**出力**

$N_o$

文字列
$S$が入力として与えられます

答えとなる整数
$N_o$を出力してください。

## 制約

$S$は`X`または`Y`からなる文字列

文字列の長さ
$|S|$ について

$1 \leq |S| \leq 10^6$

が成り立つ

## サンプルケース

### 例1

入力

### `YYYYYXYYYX`

出力

### `10`

次のように順番に`X`が増えていきます

$Y \ Y \ Y \ Y \ Y \ X \ Y \ Y \ Y \ X$

$Y \ Y \ Y \ Y \ X \ X \ X \ Y \ X \ X$

$Y \ Y \ Y \ X \ X \ X \ X \ X \ X \ X$

$Y \ Y \ X \ X \ X \ X \ X \ X \ X \ X$

$Y \ X \ X \ X \ X \ X \ X \ X \ X \ X$

$X \ X \ X \ X \ X \ X \ X \ X \ X \ X$

ここで変化がなくなるため、`X`の数は10より、`10`を出力してください

### 例2

入力

### `YYYYYYYX`

出力

### `8`

同様にすべての文字が`X`になるまで続きます

文字数は8のため、`8`を出力してください
