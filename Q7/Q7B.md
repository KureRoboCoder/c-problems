# Q7B 	リボルバー・ミー

## 問題文

(この物語はフィクションです。現実には何の関係もございません。)

ギャンブル大好き太郎君！

今日も生活費で高レバレッジを攻めますが、盟友キ・カゾエールノ＝ダイスキーと勝負をすることとなりました

ちょっと変わったリボルバー「HWHW8000」でロシアンルーレットで対決します

また、変わった点として、このリボルバー、銃弾が出る条件が決まっています

- 弾薬が1つでも入っているならば、引き金を引くと確実に「発砲」されるが、**例外条件に1つでも当てはまれば発砲されない**
    - 初回は必ず発砲しない
    - 「今までに引き金を引いた数」が**3の倍数** ならば発砲しない
    - 「「今までに引き金を引いた数」を**6で割ったあまり** 」番目に弾薬がない場合は発砲しない
    - 弾薬の合計数と「今までに引き金を引いた数」に**1より大きい公約数**があるならば発砲しない

もし、銃弾を引いてしまうと「ふわふわ」になってしまいます

そうなるとなんやかんやで今日の晩御飯がなくなってしまうかもしれません

そんな危険なギャンブルをする仲になった2人は置いといて、その勝負どちらが先に勝つかを予想しましょう！

i番目の弾薬状態
$C_i$が6つ与えられます

弾薬があるならば`o`、空ならば`x`と与えられます

先手の太郎君が勝つならば`First`、後手のキ・カゾエールノ＝ダイスキーが勝つならば`Second`を出力してください

ただし、永久に勝負がつかない場合は`None`と出力してください

## 入出力例

**入力**

$C_1 \ C_2 \ C_3 \ ... \ C_6$

**出力**

$S_o$

文字
$C_i$が6個与えられます

答えとなる文字列
$S_o$を出力してください。

## 制約

$C_i$は`x`または`o`

## サンプルケース

### 例1

入力

### `x x x o x x`

出力

### `Second`

流れは
- 先手
    - 初回より不発

- 後手(引き金の引かれた回数は1)
    - 「「今までに引き金を引いた数」を**6で割ったあまり** 」番目に弾薬がないため、不発

- 先手(引き金の引かれた回数は2)
    - 「「今までに引き金を引いた数」を**6で割ったあまり** 」番目に弾薬がないため、不発

- 後手(引き金の引かれた回数は3)
    - 「「今までに引き金を引いた数」を**6で割ったあまり** 」番目に弾薬がないため、不発

- 先手(引き金の引かれた回数は4)
    - 条件を一切満たさないため、発砲

後手の勝利のため、`Second`と出力してください


### 例2

入力

### `x x o x x o`

出力

### `None`

常に決着がつくことはあり得ません

そのため、`None`と出力してください


### 例3

入力

### `o x o x o x`

出力

### `First`
