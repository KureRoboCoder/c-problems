# Q4C 	Galaxy Abenatsu

## 問題文

(この物語はフィクションです。現実には何の関係もございません。)

銀河の覇者、ギャラクシー・アベナツは好きな3つの惑星を合体させ、相手の知能指数を下げる能力で全戦全勝してきました

この能力を使われると、どうしようもありません

そこで、あなたは軍隊を結成し、周りの味方を犠牲にすることで自分が戦えることに気づきました

しかし、人件費というのも侮ってはいけません。雇えば雇うほどお財布が寂しくなってしまいます

そこで、周りの惑星の状態から何回能力を使われるかを求める必要があります

2つの整数
$L, R$が与えられるので、範囲
$L$以上
$R$以下で任意の**3つの整数の和が3の倍数**であるトリオの数を出力してください

また、整数は同じものを何度使っても構いませんが、
$L$以上
$R$以下の整数
$n, m, p$と定義するとき、
$(A_n, A_m, A_p) \ (A_n, A_p, A_m)$

$(A_m, A_n, A_p) \ (A_m, A_p, A_n)$ 

$(A_p, A_n, A_m) \ (A_p, A_m, A_n)$ は同じトリオだと考えます


## 入出力例

**入力**

$L \ R$

**出力**

$N_o$

答えとなる整数
$N_o$を出力してください

## 制約

$L, R$は整数である

$1 \leq L \leq 98$

$3 \leq R \leq 100$

$L + 2 \leq R$

## サンプルケース

### 例1

入力

### `1 3`

出力

### `4`

能力を使われるトリオは

$(1, 1, 1) \ (1, 2, 3)$

$(2, 2, 2) \ (3, 3, 3)$

の4つのため、4と出力してください


### 例2

入力

### `1 5`

出力

### `13`

能力を使われるトリオは

$(1, 1, 1) \ (1, 1, 4)$

$(1, 2, 3) \ (1, 3, 5)$

$(1, 4, 4) \ (2, 2, 2)$

$(2, 2, 5) \ (2, 3, 4)$

$(2, 5, 5) \ (3, 3, 3)$

$(3, 4, 5) \ (4, 4, 4)$

$(5, 5, 5)$

の13種類のため、13と出力してください

### 例3

入力

### `10 20`

出力

### `98`

10から20の間の整数を条件に従うと98通り存在します
